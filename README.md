# Unbury

Unbury is an AI external-memory and execution assistant. Users can dump messy information such as messages, screenshots, PDFs and voice notes, then review the tasks, deadlines and context extracted from it.

## Frontend

- Next.js
- TypeScript
- Tailwind CSS
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
